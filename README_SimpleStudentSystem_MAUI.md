
# 🎓 Simple Student System – .NET MAUI App

**Simple Student System** is a cross-platform application built using **.NET MAUI**, designed to manage basic student records. It showcases modern UI, MVVM pattern, and database integration, making it ideal for learning or lightweight academic use.

---

## 📌 Features

- 👨‍🎓 Add, update, and delete student records
- 📋 List all registered students
- 🔍 Search functionality
- 💾 Local SQLite database integration
- 🌐 Responsive UI using .NET MAUI
- 🧠 MVVM Architecture (Model-View-ViewModel)

---

## 🛠️ Built With

- ✅ [.NET MAUI](https://learn.microsoft.com/en-us/dotnet/maui/) – Cross-platform UI framework
- ✅ C#
- ✅ SQLite – Lightweight local DB
- ✅ MVVM Design Pattern

## 🚀 Getting Started

### Prerequisites

- Visual Studio 2022 or newer
- .NET 7 SDK or higher
- MAUI workload installed

### Run the Project

```bash
git clone https://github.com/your-username/SimpleStudentSystem-MAUI.git
cd SimpleStudentSystem-MAUI
```

- Open `.sln` file in Visual Studio
- Select target device (Android, Windows, iOS)
- Run the project
